# Plans

Briefs for work that's planned but not started. Each has the background a new session needs, steps that each end on
a "Done when", and a kickoff prompt to paste into a new session.

| Plan | What | Start with |
|---|---|---|
| [ci-health.md](ci-health.md) | A full CI run you can trust, in about 15 minutes: every failing and flaky test fixed at its cause, the suite sharded | First: every later release depends on it |
| [replays.md](replays.md) | Save any play in one press, share it in two taps, and a library of recent saves | After CI health |
| [perf-pass.md](perf-pass.md) | 60 fps on mid-range phones, and a Battery saver setting | Any time |
